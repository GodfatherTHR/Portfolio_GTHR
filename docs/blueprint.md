# **App Name**: Shariful Haque Portfolio

## Core Features:

- Hero Section: Display a visually appealing hero section with animated background, personal introduction and clear call to action.
- Projects Showcase: Showcase past projects with descriptions, images, and links. Allow filtering or categorization.
- Experience Timeline: Detail professional history, including roles, responsibilities, and achievements.
- Skills Visualization: Display skills using progress bars, icons, or other visual elements to represent proficiency levels.
- Contact Section: Provide contact information, social media links, and a contact form for inquiries.
- Admin Panel: Implement an admin panel with authentication to allow for easy content updates (projects, experience, skills, etc.).

## Style Guidelines:

- Primary color: Purple (#6B46C1) to reflect creativity and sophistication.
- Background color: Light grey (#F7F5FA) to ensure content readability.
- Accent color: Pink (#D53F8C) to draw attention to interactive elements.
- Font: 'Russo One' (sans-serif) for a modern and bold aesthetic. Note: currently only Google Fonts are supported.
- Card-based layout for showcasing projects and experience, maintaining a clean and structured presentation.
- Use the three.js wave animation with dithering effect as the hero section's background.
- Ensure the text contrast meets WCAG AA standards, with a minimum font size of 16px for body text.
